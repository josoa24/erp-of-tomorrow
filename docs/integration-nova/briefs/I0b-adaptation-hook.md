## Build (novaui only, small and fast, with tests)
1. `features/eclipse/constants/adaptations.ts`: module keys (`stock`, `ventes`, `relations`, `equipe`), adaptation keys (`stock.lots-peremption`, `ventes.mobile-money-credit`, `relations.nif-plafond-credit`, `equipe.avances-salaire`), map adaptationKey -> moduleKey, French request examples and summaries identical to the Figma bars (stock « Ajoute le n° de lot et la date de péremption, avec une alerte 30 jours avant » / « Eclipse a ajouté : colonnes N° de lot et Péremption · alerte J-30 · filtre Expire bientôt »; ventes « Ajoute le paiement Mobile Money (MVola, Orange Money) et le suivi des ventes à crédit » / « Eclipse a ajouté : colonne Paiement · filtre À crédit · indicateur Crédit en cours »; relations « Ajoute le NIF/STAT des clients professionnels et un plafond de crédit » / « Eclipse a ajouté : colonnes NIF / STAT et Plafond crédit · filtre Professionnels · alerte de dépassement »; equipe « Ajoute les avances sur salaire, plafonnées à 30 % du salaire » / « Eclipse a ajouté : colonnes Avance et Plafond · filtre Avance demandée · validation par le gérant »).
2. `features/eclipse/types/adaptation.ts`: `AdaptationProposal {adaptationKey, moduleKey, request, title, summary}`, `AdaptationActivation {moduleKey, adaptationKey, activatedBy, activatedAt}`.
3. `features/eclipse/api/adaptationsApi.ts`: `fetchAdaptations()` GET /api/modules/adaptations, `activateAdaptation({moduleKey, adaptationKey})` POST /api/modules/adaptations.
4. `EclipseAdaptationProvider` (mounted inside the AppShell, next to EclipseDockProvider): preview state per module with `startPreview(proposal)`, `clearPreview(moduleKey)`; syncs the URL search param `eclipse=<adaptationKey>` both ways (opening `/stock?eclipse=stock.lots-peremption` starts the preview with the catalog request/summary as default texts; clearing removes the param).
5. `useModuleAdaptation(moduleKey)` -> `{ active, preview, isApplying, apply, cancel, canApply }`: `active` from React Query `['adaptations']` (a 404/503 from module-service means "none active": non-blocking auxiliary data, no error page; other errors go through useApiError), `preview` from the provider, `canApply` = current role ADMIN, `apply` = POST then invalidate `['adaptations']`, clear preview, success toast « Adaptation appliquée pour l'équipe » (API error -> error page), `cancel` = clear preview. While a preview exists for the current route's module, the AppShell shows the socle `AdaptationBar` (request = preview.request, summary = preview.summary) instead of the EclipseDock; wire it here.
6. Tests for api, provider (URL sync), hook (active/preview/apply success/apply error/cancel/canApply by role), and the shell switching dock <-> AdaptationBar. lint, tsc -b, test, build green. Commit with the usual rules.
